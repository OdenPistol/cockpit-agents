# Lanterne, un tableau de bord libre pour suivre ce que coûtent vos agents

Le collectif (fictif) Phare publie Lanterne, un outil libre sous licence MIT qui affiche en continu le coût, la durée et le statut des tâches confiées à des agents d'IA. L'outil fonctionne en local, sans compte ni base de données : il lit simplement un fichier journal écrit après chaque passage.

Ses auteurs insistent sur trois principes : ne montrer que des coûts réellement mesurés, jamais des projections ; prévenir quand un agent n'a pas tourné à l'heure prévue ; refuser de lancer un agent dont le budget du jour serait dépassé.

Lanterne compte déjà 1 200 étoiles sur la plateforme de code du collectif. Plusieurs utilisateurs signalent que le plus utile est l'alerte « agent en retard », qui révèle des tâches silencieusement oubliées.
